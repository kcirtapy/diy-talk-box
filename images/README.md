# Photos

Build photos for the main README go in this folder. The README already has hidden slots for these file names:

| File name | Shows |
| --- | --- |
| `talkbox.jpg` | The finished talk box |
| `wiring.jpg` | The capacitor soldered into the + lead |
| `adapter.jpg` | The printed adapter on the driver |
| `playing.jpg` | The talk box in use |

Use JPG or PNG. GitHub can't display HEIC photos.
